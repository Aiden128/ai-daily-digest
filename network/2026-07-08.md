## 一、頭條（過去 7 天重點）

### 1. The Next Platform 7/6〈As Goes AI Compute, So Goes Ethernet Networking〉——Q1 2026 IDC 數據揭示 NVIDIA SpectrumX 以 $2.1B 季度營收 + 2.9× YoY 奪 DC Ethernet switch #1，800G switch 季度營收 10.3× YoY 達 $3.58B

[The Next Platform 7/6〈As Goes AI Compute, So Goes Ethernet Networking〉](https://www.nextplatform.com/connect/2026/07/06/as-goes-ai-compute-so-goes-ethernet-networking/5267007)（[The Next Platform](https://www.nextplatform.com)，7/6，**Timothy Prickett Morgan 發布**）**首次公開 Q1 2026 IDC 全球 Ethernet switch 市場分析**，**這是 2026 H1 最重要的 fabric 市場結構數據**，**10 個關鍵數據點**：

- **DC Ethernet switch 季度營收 $10B 級**：**(a) 整體 server 市場 Q1 2026 季度營收 $122.62B，YoY +30.4%**；**(b) Ethernet switch 整體 Q1 2026 季度營收 $15.36B，YoY +39.8%**（**不含 DPU / NIC / cable**）；**(c) DC Ethernet switch 季度營收 $10B+，YoY +61%**——**這是 2026 H1 最重要的「AI 推論負載引爆 DC Ethernet switch 採購」 數據點**；**(d) edge / campus Ethernet switch 季度營收 $5.35B，YoY +12.3%**——**DC Ethernet 成長速度是 edge/campus 的 5×**，**這是 AI 推論 vs general IT 的成長速度差距**。
- **NVIDIA SpectrumX 首次奪 DC Ethernet switch #1**：**(a) NVIDIA DC Ethernet switch 季度營收 $2.1B，YoY 2.9× 成長**（**IDC 確認 NVIDIA 的營收數字僅含 SpectrumX switch，不含 cable/NIC/DPU/InfiniBand**）；**(b) Cisco DC Ethernet switch 季度營收 $1.78B，YoY +43.2%**；**(c) Arista DC Ethernet switch 季度營收 $2.07B，YoY +40.1%**——**NVIDIA 以 $2.1B 季度營收超越 Arista ($2.07B) + Cisco ($1.78B) 成為 DC Ethernet #1**（**雖然 NVIDIA 在 Q4 2025 曾打敗 Cisco 但被 Arista 略勝**）。**這是 NVIDIA SpectrumX 在「post-Q2 2025 #1 起步」 後的「Q1 2026 確認 #1」**，**對 2026 H2 fabric 採購的 practical 含義**：(i) **NVIDIA SpectrumX 已成為 hyperscaler DC Ethernet switch 採購的 default reference**（與 Arista 7800R3 / Cisco 9300 / Cisco SiliconOne 並列）；(ii) **SpectrumX 800G + ConnectX-8 + BlueField-3/4 構成的「NVIDIA end-to-end AI fabric stack」 在 Q1 2026 已達 $2.1B 季度營收**——**這是「AI 推論負載引爆 fabric 採購」 的最直接證據**。
- **800G switch 季度營收 10.3× YoY 達 $3.58B**：**(a) 800G switch Q1 2026 季度營收 $3.58B，YoY 10.3× 成長**（**Q4 2025 800G switch 季度營收約 $0.35B**）；**(b) 但 Q1 2026 vs Q4 2025 環比 -14.3%**（**Q1 通常低於 Q4**）；**(c) 800G native switch 佔 Q1 2026 DC Ethernet switch 營收 35.8%**；(d) **native 200G/400G switch 佔 Q1 2026 DC Ethernet switch 營收 34.1%（$3.41B）**——**但 200G/400G 季度營收 YoY -10.4%、QoQ -52%**（**採購從 200G/400G 快速轉向 800G**）；(e) **cost per Gb/sec for native 800G 為 $0.61/Gbps**，**vs 200G/400G blended $0.53/Gbps**（**800G 略貴但接近 200G/400G 成本**）；(f) **native 100G switch 為 $1.20/Gbps**（**2× 800G 成本**）；(g) **native 1G switch 為 $10-11/Gbps**（**17-18× 800G 成本**）——**「100G 對 AI fabric 不夠用，1G 對任何認真的 network 不夠用」 是 Timothy Prickett Morgan 的 actionable 結論**。
- **Router 市場 Q1 2026 季度營收 $3.75B，YoY +11.3%**：(a) **cloud SP 佔 router 營收 77.2%（$2.9B，YoY +12.9%）**——**hyperscaler 持續是 router 採購主力**；(b) **enterprise router 季度營收 $867M，YoY +6.1%**——**enterprise router 採購週期延長**；(c) **regional breakdown**：Americas +19.6%，EMEA +9.8%，Asia/Pacific +2.8%——**US 在 IT 基礎建設的「arms race」 中領先**。
- **對 2026 H2 fabric 採購的 practical 含義**：(i) **新購 hyperscaler DC Ethernet switch 採購應以 800G 為 baseline**（SpectrumX 800G / Arista 7800R3 / Cisco SiliconOne G200 已是 reference design），**native 200G/400G 已是 legacy**；(ii) **NVIDIA SpectrumX 在 Q1 2026 已達 $2.1B 季度營收 + 2.9× YoY + DC Ethernet #1**——**這是 2026 H1 最重要的「end-to-end AI fabric stack」 驗證**，**新購 hyperscaler 應以 SpectrumX + ConnectX-8 + BlueField-3 為 reference 評估**；(iii) **800G switch cost per Gbps $0.61 vs 100G $1.20 是 2× 差距**——**新購 100G 已是「明顯 cost-inefficient」**，**採購者必須有「800G 已 ready」 的內部 SLA 標準**；(iv) **1.6T / 3.2T switch 預期 2026 H2 出現**（**SpectrumX 1600G + Tomahawk 6 + Arista 7800R4 + Cisco SiliconOne 256**）——**新購 hyperscaler 100K+ GPU cluster 應直接採購 1.6T 為 baseline**。

### 2. uccl-project/rdmatop v0.1.22 (7/6)——RDMA 觀測工具首次整合 NVLink + AMD XGMI + device sort：cross-vendor GPU 互連 fabric 觀測的關鍵里程碑

[uccl-project/rdmatop v0.1.22](https://github.com/uccl-project/rdmatop/releases/tag/v0.1.22)（[uccl-project/rdmatop](https://github.com/uccl-project/rdmatop)，7/6 release）**首次新增「NVLink 支援 + AMD XGMI 監控 + device sort」 三項功能**——**這是 UC Berkeley Sky Lab 的「UCCL」（UCCloud Laboratory） 計畫在「cross-vendor GPU 互連觀測」 領域的關鍵里程碑**。**v0.1.22 release 包含 6 項主要改進**（**這是 v0.1.19/v0.1.20/v0.1.21 的「feature continuation」**）：

- **PR #26 "Add Nvlink Surpport"（by @murez）**——**rdmatop 開始支援 NVIDIA NVLink GPU 互連 fabric 觀測**（**這是 rdmatop 從「RoCE v2 / IB cross-provider RDMA 觀測」 擴展到「NVLink GPU 互連」 的關鍵一步**）。**對 2026 H2 fabric 觀測的含義**：(i) **NVLink 是 NVIDIA GB200/GB300 NVL72 rack-scale 的關鍵 fabric**（**每個 GB300 NVL72 rack 有 18 個 GB300 SuperChip + 9 個 NVLink switch tray**，**總頻寬 130 TB/s**）；(ii) **rdmatop 的 NVLink 觀測讓 hyperscaler 可以在「NVLink 故障 → GPU 通訊掉速」 的 incident response 上做 root cause analysis**；(iii) **與 rdmatop 既有的 RoCE v2 / IB 觀測結合**，**可以實現「end-to-end GPU + fabric 觀測」**（**從 GPU memory → NVLink → PCIe switch → ConnectX-8 → Quantum-X / Spectrum-X**）。
- **PR #28 "feat: support device sort"（by @crazyguitar）**——**rdmatop 開始支援 device 列表排序**（**這是 large cluster 管理的基本需求**）；**PR #29 "feat: support AMD XGMI monitoring"（by @crazyguitar）**——**rdmatop 開始支援 AMD XGMI GPU 互連 fabric 觀測**（**這是 rdmatop 從「NVIDIA-only GPU 互連觀測」 擴展到「AMD + NVIDIA 跨 vendor」 的關鍵一步**）。**對 2026 H2 fabric 觀測的含義**：(i) **AMD XGMI 是 AMD MI300X/MI400 8-GPU SuperChip 的關鍵 fabric**（**每個 MI400 SuperChip 有 8 個 MI400 GPU + XGMI 互連**，**總頻寬 1.5 TB/s**）；(ii) **rdmatop 的 AMD XGMI 觀測讓 hyperscaler 可以在「MI300X/MI400 + XGMI 故障 → GPU 通訊掉速」 的 incident response 上做 root cause analysis**；(iii) **rdmatop 是「**第一個 cross-vendor GPU 互連觀測工具**」**——**支援 NVLink + XGMI 兩條 GPU 互連 fabric**，**這是 2026 H2 採購 MI300X/MI400 + GB200/GB300 雙 vendor GPU cluster 的關鍵 enable 技術**。
- **PR #30 "perf(xgmi): cache static link speeds, halving per-refresh cost"（by @crazyguitar）**——**XGMI 觀測的 performance optimization**（**XGMI link speed 是 static 的，cache 後 refresh 成本減半**）；**PR #31 "feat: add intranode examples"（by @crazyguitar）**——**新增 intranode GPU 互連範例**（**讓使用者可以快速上手 XGMI / NVLink 觀測**）；**PR（unmerged）"feat: Separate XGMI and NVLINK to an independent tab"（by @crazyguitar）**——**rdmatop 開始把 XGMI 與 NVLink 觀測分到獨立 tab**（**這是 cross-vendor GPU 觀測 UI 的關鍵 design**）。
- **與 rdmatop v0.1.19/v0.1.20/v0.1.21 的延續性**：(a) **v0.1.19 (7/1) 的「feat: support traffic recording」**——**RDMA 封包 record/replay**；(b) **v0.1.20/v0.1.21 (7/4)**——**只是 changelog 修訂**；(c) **v0.1.22 (7/6) 的「NVLink + XGMI + device sort」**——**cross-vendor GPU 互連 fabric 觀測**。**整個 7 月 rdmatop 已從「RoCE v2 / IB 觀測」 升級到「NVLink + XGMI + RoCE v2 / IB 觀測」 的「**cross-vendor fabric 觀測 baseline**」**。
- **對 2026 H2 fabric 觀測的 practical 含義**：(i) **新購 hyperscaler / 主權 AI 基建 cluster 應把 rdmatop v0.1.22 視為「**cross-vendor GPU 互連 + RDMA 觀測**」 baseline**，**無論 cluster 是 NVIDIA-only (Spectrum-X + NVLink) 還是 AMD-only (Pensando + XGMI) 還是 mixed**；(ii) **rdmatop v0.1.22 的 NVLink 觀測 對 NVIDIA GB200/GB300 NVL72 rack-scale incident response 是 critical feature**——**hyperscaler 可以 record + replay NVLink traffic 做 root cause analysis**；(iii) **rdmatop v0.1.22 的 AMD XGMI 觀測 對 AMD MI300X/MI400 SuperChip incident response 是 critical feature**——**這讓「AMD ROCm + MI400 + Pensando DPU 對 NVIDIA NVLink + Spectrum-X + Quantum-X」 的競爭軸線 在 observability 工具上首次對等**；(iv) **rdmatop v0.1.22 的 traffic recording (v0.1.19) + NVLink/XGMI 觀測 (v0.1.22) + device sort (v0.1.22) 構成「**end-to-end cross-vendor fabric 觀測 stack**」**，**是 2026 H2 採購主權 AI 基建 / hyperscaler cluster 的「observability baseline」**。

### 3. Light Reading 6/30〈South Korea plans massive 18.4GW AI data center buildout by 2035〉——主權 AI 基建的「power-grid × AI fabric」 整合（已在 07-05/07-07 整理，本週加上「NVIDIA SpectrumX 奪 DC Ethernet #1 × 主權 AI 基建 18.4GW」 的整合觀察）

[Light Reading 6/30〈South Korea plans massive 18.4GW AI data center buildout by 2035〉](https://www.lightreading.com/data-centers/south-korea-plans-massive-18-4gw-ai-data-center-buildout-by-2035)（[Light Reading](https://www.lightreading.com)，6/30，**已在 07-05/07-07 digest 整理**）揭露 **南韓計劃至 2035 年建置 18.4GW AI 資料中心**。**本週的延伸觀察**——**「NVIDIA SpectrumX 奪 DC Ethernet #1 × 主權 AI 基建 18.4GW」 整合採購 framework**：

## 二、Research Spotlight（已整理內容的延伸觀察）

### Spotlight 1. The Next Platform 6/30〈Optical Scale-Up Fabrics Are Limited By Manufacturing, Not Architecture〉（已在 07-05/07-06/07-07 整理）——本週 actionable 結論：**rack-scale co-packaged optics + silicon photonics 在 2027 H1 量產前，hyperscaler 不應採購 100K+ GPU scale-up cluster**；**+ Q1 2026 IDC 數據確認 800G switch 已成 DC Ethernet baseline**

[The Next Platform 6/30〈Optical Scale Up Fabrics Are Limited By Manufacturing, Not Architecture〉](https://www.nextplatform.com/connect/2026/06/30/optical-scale-up-fabrics-are-limited-by-manufacturing-not-architecture/5264399)（[The Next Platform](https://www.nextplatform.com)，6/30，**已在 07-05/07-06/07-07 digest 整理**）指出 **AI 資料中心 scale-up fabric 的 constraint 已從「architecture」轉移到「manufacturing」**。**本週的延伸 actionable 結論 + Q1 2026 IDC 數據交叉驗證**：

- **「2026 H2 不應採購 100K+ GPU scale-up cluster」 的工程理由**：(a) **rack-scale co-packaged optics (CPO) + silicon photonics 在 2026 H2 仍處於 early deployment 階段**——**NVIDIA SpectrumX 1600G + Tomahawk 6 + CPO 的「2027 H1 量產」 計劃可能 delay**（silicon photonics 雷射陣列的量產工藝瓶頸是 6/30 文章的核心訊息）；(b) **hyperscaler 採購 100K+ GPU scale-up cluster 的 TCO 上限 由 co-packaged optics + silicon photonics 的量產 yield 決定**——**量產 yield 不達標 → 採購單價超支 20-40%**；(c) **2026 H2 採購 100K+ GPU scale-up cluster 等於「押注 2027 H1 量產準時 + 採購單價在預算內」 兩個 high-risk assumption**——**對 hyperscaler 而言，這是 high-risk 押注**。
- **「Q1 2026 IDC 數據交叉驗證」**：**(a) 800G switch 季度營收 10.3× YoY 達 $3.58B**——**800G 是 Q1 2026 的 DC Ethernet baseline**；(b) **NVIDIA SpectrumX 800G 在 Q1 2026 達 $2.1B 季度營收 + DC Ethernet #1**——**SpectrumX 800G 已是 reference 採購**；(c) **「2026 H2 採購 100K+ GPU scale-up cluster」 的決定瓶頸不是 800G switch（已 ready）而是 1.6T/3.2T + CPO + silicon photonics（**未 ready**）**——**這是 6/30 Optical Scale-Up Fabrics 文章的 Q1 2026 數據驗證**。
