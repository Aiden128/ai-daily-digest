具體內容(從 [HN 7/20 thread](https://news.ycombinator.com/item?id=48973869) + Levent Alpöge 7/20 X post):**Jacobian Conjecture 是什麼** — 1939 年由 O.H. Keller 提出,問 「**所有 Jacobian 矩陣 determinant 是常數的多項式映射,是否一定是可逆的**」,80 多年來在 commutative algebra / algebraic geometry 是核心 open problem,2015 年 arXiv 2204.14178 證明 「**counterexample 必須 degree ≥ 100**」;**Levent 找到 degree-7 反例** — 7 個 variables 的 explicit polynomial mapping (P, Q),Jacobian 矩陣 determinant 是常數,但 P 跟 Q 不可逆 — 這跟 2015 年的下界直接矛盾,需要修正既有文獻的某些 boundary condition assumption。**為什麼用 Fable** — Levent 在 Anthropic 7/20 thread 引用 Fable 的 「**explicit reproducible reasoning**」 設計,prompt 直接列出 「**search space、constraint、format、verify**」,4 個 subagent 並行做 「**brute force polynomial candidate + 過濾 + counterexample check + symbolic verification**」;**LLM 跟數學家 role 分配** — Levent 自己設計 「**把 search space 收斂到 7 維**」 的 framework,Fable 跑搜索;**Hacker News 大量辯論** — (a) 一派人質疑 「**沒公開 chat history = marketing stunt**」 ([HN ID 48976123](https://news.ycombinator.com/item?id=48973869) 「**Unless they share the full LLM chat history, I'm gonna assume that this is a marketing stunt**」);(b) 反對方 「**如果 Levent 真的解出來, credit 給 Claude 是 human PR; 如果他沒解出來, 公開 chat log 也只是 backfill**」([HN ID 48977051](https://news.ycombinator.com/item?id=48973869) 「**A mathematician working for Anthropic solved a problem mathematicians have been working on for more than a century, and then credited it to Claude for PR purposes**」);(c) 中間派「**就算 Levent 設計了 search space, Fable 把搜尋空間砍到 7 維本身就是大貢獻**」([HN ID 48979643](https://news.ycombinator.com/item?id=48973869) 「**Fable makes experts able to solve things is still a big story**」)。

[HN 7/20 thread](https://news.ycombinator.com/item?id=48975665) + [Searchlight Cyber 7/20 full report](https://slcyber.io/research-center/exploit-brokers-pay-500000-for-a-wordpress-rce-i-found-one-with-gpt5-6/) + [OpenAI CDC prompt 公開 PDF](https://cdn.openai.com/pdf/04d1d1e4-bc75-476a-97cf-49055cd98d31/cdc_prompt.pdf) + [Searchlight 7/20 online checker wp2shell.com](https://wp2shell.com/)。Searchlight Cyber 安全研究員 7/20 公開一份 full report:用 GPT-5.6 Sol Ultra + 改寫自 OpenAI 7/18 公開的 Cycle Double Cover 證明 prompt,**6 小時內用 4 個 agent 在乾淨的 WordPress source tree 找到 pre-auth SQL injection + post-exploitation chain 到 RCE**。技術細節是 WordPress 5.6 (2020) 引入的 `/wp-json/batch/v1` endpoint 把 authentication 帶進 subrequest,SQL injection 在不需登入的 subrequest 內觸發,再透過 PHP object injection 升級到 admin 最後 RCE read `/flag`。Total cost: **$200/月 訂閱的 50%** = **$25 USD**;**exploit broker 公開報價 $500,000+**。

### 1.4 Saivineeth147 7/20 公開 LoRA Speedrun — 開源 fine-tuning leaderboard,5 分鐘 GPU 訓練 baseline 統一,打破 「**fine-tuning 只有大公司能做**」 印象

[HN 7/20 thread](https://news.ycombinator.com/item?id=48974325) + [GitHub Saivineeth147/lora-speedrun](https://github.com/Saivineeth147/lora-speedrun) + [Modal Labs 7/20 sponsor blog](https://modal.com/blog/lora-speedrun)。HN 7/20 high-engagement thread 公開 Saivineeth147 7/20 釋出的 「**LoRA Speedrun**」 開源專案,目標是 「**在固定的 5 分鐘 H100 GPU 預算下, 任何研究者可以用一致的 baseline 跑 LoRA fine-tuning 來比較 algorithm**」;配套有 Modal Labs 贊助的 5 分鐘 H100 spot instance 配額,每個 submission 都跑同一個 dataset (SlimPajama 6B subset) + 同一個 model (Llama 3.2 1B) + 同一個 budget (5 min H100) + 同一個 eval (perplexity on a held-out validation set),打破過去 fine-tuning benchmark 「**各自跑不同 dataset / model / budget / eval, 無法直接比較**」 的問題。

具體內容(從 [GitHub Saivineeth147/lora-speedrun](https://github.com/Saivineeth147/lora-speedrun) + [Modal Labs 7/20 blog](https://modal.com/blog/lora-speedrun)):**為什麼需要 LoRA Speedrun** — 過去 12 個月 LoRA / QLoRA / DoRA 等 parameter-efficient fine-tuning 變體爆發,但 「**各自 paper 的 baseline 不同, 沒辦法 reliable 比較**」;**LoRA Speedrun 的設計** — (1) **固定 5 分鐘 H100** → 強迫 algorithm 設計者 optimize 「**quality per compute**」 而不是 「**quality per epoch**」;(2) **固定 Llama 3.2 1B + SlimPajama 6B** → 排除 「**bigger model = better**」 的混淆變量;(3) **固定 eval (held-out perplexity)** → 排除 「**overfit to benchmark**」 的問題;(4) **leaderboard public** → community 可以直接 submit + reproduce;**第一波 submissions** — (a) stock LoRA baseline,(b) DoRA (Decomposed LoRA),(c) AdaLoRA (adaptive rank),(d) 兩個 community-submitted variants;**leaderboard 結果** — DoRA 比 stock LoRA perplexity 降低約 1.2%,AdaLoRA 因為 rank 動態調整在 5 分鐘 budget 下 「**rank warmup 浪費 compute**」 反而 perplexity 高 0.5%;**社群反應** — HN 7/20 high-engagement, 「**5 分鐘 H100 + 統一 baseline**」 被認為是 「**fine-tuning algorithm comparison 的 ImageNet moment**」 ([HN ID 48975300](https://news.ycombinator.com/item?id=48974325) 「**This is what the field needed for years — a real ImageNet moment for LoRA**」),也有人 debate 「**5 分鐘 budget 太短, 真實 use case 是 1-24 小時 fine-tuning**」 ([HN ID 48974777](https://news.ycombinator.com/item?id=48974325) 「**In production we run 6h fine-tunes, 5min results don't generalize**」)。

對開發者的意義:這是 [HF Open Llama Leaderboard](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard) + [lmsys Chatbot Arena](https://chat.lmsys.org) + [SEAL Leaderboard](https://scale.com/leaderboard) 之後,**第一個 「**fine-tuning algorithm 在固定 compute budget 下的 unified benchmark**」**。對企業 IT 採購:「**open weight fine-tuning 不再是大公司專利**」 對 2026 H2 「**enterprise 對 model customization 採購 framework**」 是 7/20 new 維度;**5 分鐘 H100 = $0.30** 對 「**per-algorithm experiment cost**」 從 「**$50-500**」 砍到 「**$0.30**」, 對 enterprise 內部 「**algorithm 試錯 budget**」 從 「**vendor benchmark only**」 推到 「**自己 run small-scale benchmark**」 是 7/20 first concrete shift;對 [Nathan Lambert 7/12 〈6 months to live for open models〉](/daily/2026-07-19) + [Thinking Machines 7/15 Inkling 1M context open model](/daily/2026-07-20) + [Kimi K3 + Qwen 3.8 open weights](#-今日頭條) 的 「**open weight 攻上 frontier**」 7/12-7/20 推進互補:**open weight 不只在 「**pre-trained model 維度**」 攻上 frontier, 也在 「**fine-tuning algorithm 維度**」 攻上 「**reproducible benchmark**」, 對企業 IT 「**open weight 採購 = pre-trained model + fine-tuning algorithm + reproducible benchmark 三軸**」 是 7/20 first concrete shift**。

### 1.5 Meta 7/20 公開 Inertia-1 — 統一 motion foundation model,把 「**角色動作 / 物體運動 / 相機運動**」 三種 motion 整合到 single transformer,目標是 「**任何 3D 場景中物件的 6DoF motion 統一表示**」

### 3.1 emergingtrajectories.com 7/20 〈Kimi K3, Qwen 3.8, and Anthropic's (Potential) Unravelling〉 量化 frontier lab economics,把 「**open weight + 自建 infrastructure = 唯一 sustainable path**」 推到 2026 H2 frontier vendor 競爭 center
