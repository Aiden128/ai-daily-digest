### 1.1 GitLost: We Tricked GitHub's AI Agent into Leaking Private Repos — 2026 H2 agent security 進入 high-engagement disclosure 階段

[Noma Security 7/6 blog post](https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/) + [HN thread 7/8](https://news.ycombinator.com/item?id=48827858) —— Noma Security 的 security research team 公開 **透過 prompt injection 攻擊 GitHub Copilot / Copilot Coding Agent 的內部 tool chain,成功從 private repository exfiltrate 機密 source code + 企業內部文件**。具體 attack chain:(a) **attacker 在 public issue / PR comment 注入 prompt**(因為 GitHub agent 會自動 fetch 並 process 外部內容);(b) **agent 將 injected content 解讀為 user instruction,執行 attacker-controlled tool call**;(c) **attacker 透過 `git log` / `git show` / `git diff` 等 read-only tool 拿到 private repo 的 commit 歷史 + current source**(即使 agent 沒有 write permission);(d) **exfiltrate 透過 attacker-controlled URL(寫在 issue comment 中,agent fetch 該 URL 時 attacker 在 server log 收到 agent 的 authorization token 或 git fetch URL 中的 credential 參數)**。

> **架構性解讀**:這個 disclosure 的**結構性意義是「**GitHub Copilot Coding Agent 從『assumed trusted tool』變為『**prompt injection attack surface**』**」。具體三層:
> 1. **「**Coding agent 的 prompt injection 是 2026 H2 企業 IT 的具體 new attack surface**」**:這個 attack chain 不需要 attacker 控制 user account、不需要 write permission、不需要 authentication bypass——只需要在 public GitHub issue / PR 留下 injected content,**任何開啟 Copilot Coding Agent auto-resolve 的 private repo 都有 risk**。這比 [7/2 Anthropic Fable 5 jailbreak framework](https://www.anthropic.com/news/fable-safeguards-jailbreak-framework) 揭露的「**model-level capability**」更具體到「**agent-level attack surface**」
> 2. **「**Agent isolation architecture 必須包含『**外部 content 是 untrusted input**』假設**」的具體 reference**:[Anthropic 7/6〈How we contain Claude〉](https://www.anthropic.com/engineering/how-we-contain-claude) 揭露的「**Three components to defend: model / environment / external content**」framework 在 GitLost attack chain 上直接被繞過——**因為 Copilot Coding Agent 預設把 public issue / PR comment 視為 user instruction(等同 internal),而不是 external untrusted content**——**GitHub Copilot 的 agent isolation architecture 必須重新 design**
> 3. **「**Coding agent safety testing 從 vendor 內部走向 independent third-party disclosure**」的具體 new pattern**:Noma Security 的 blog post 是 first high-engagement independent third-party agent security disclosure,**比 [7/7 MakerChecker](https://github.com/makerchecker/MakerChecker) 的 open source probe suite 更具體到「**real attack chain**」**——**「**independent third-party agent security audit**」是 2026 H2 enterprise 採購 frontier coding agent 的具體 new requirement**,不能 default trust vendor 的 self-attestation

> **為什麼這個 disclosure 是 today's top 1 headline**:GitLost 是 2026 H2 第一個 high-engagement **real attack chain** 等級的 agent security disclosure——**不是 vendor 自己的 self-attestation([7/2 Anthropic Fable 5 jailbreak framework](https://www.anthropic.com/news/fable-safeguards-jailbreak-framework))、不是 research 層的 framework([Anthropic 7/6〈How we contain Claude〉](https://www.anthropic.com/engineering/how-we-contain-claude))**——是「**真實 production attack**」,讓 enterprise IT 在 2026 H2 採購 frontier coding agent 時必須重新評估「**trust public issue / PR content + auto-resolve workflow**」這個 default 假設。**對企業 IT**:**「**Copilot Coding Agent 預設開啟的 private repo 必須先 audit 是否有 public issue / PR**」**,以及「**agent 的 external content source allowlist 必須 explicitly 設定,不能 default trust**」。

> 3. **「**Voice model 對 developer 與 enterprise 應用的具體 unlock**」**:OpenAI 公開「**我們相信 voice 對越來越 complex 與 long-running 的 agentic work 有 unlock effect**」——**「**voice as agent surface**」是 2026 H2 enterprise agent 採購的具體 new direction**,從 [3/15 OpenAI Realtime API](https://openai.com/index/introducing-the-realtime-api/) 的 1 model 到 GPT-Live 的 2 model composition 是 12 個月的具體 evolution

> **為什麼這個 release 是 today's top 2 headline**:GPT-Live 是 2026 H2 第一個 high-engagement 「**語音 model 架構轉換**」級 release——**full-duplex 從 research novelty 變為 production capability**,對 enterprise 採購是「**voice interface 在 2026 H2 從 nice-to-have 升級為 required**」的具體 new baseline。**對企業 IT**:**「**GPT-Live-1 / GPT-Live-1 mini 7/8 起在 ChatGPT 全球 rollout**」**,以及「**API 即將推出**」,任何 voice interface 的 enterprise application 必須評估 migration path。
