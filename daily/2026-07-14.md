### 1.4 Claude Code vs OpenCode 33k vs 7k token overhead 量化, 7/12 systima.ai 是 2026 H2 「**coding agent 從功能 feature 走到 unit cost transparency**」 的具體 new baseline disclosure

[systima.ai 7/12〈Claude Code Is Way More Token-Hungry Than OpenCode. We Measured Exactly How Much〉](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) + [HN thread 7/12](https://news.ycombinator.com/item?id=48881170)—— systima.ai 7/12 公開 對 Claude Code 2.1.207 跟 OpenCode 1.17.18 (兩者 pinned to `claude-sonnet-4-5`, 2026-07) wire-level measurement 結果, 具體四個 finding: (a) **Baseline overhead 量化: 對 「**reply with exactly: OK**」 22 character prompt, Claude Code 32,800 tokens (system prompt 3 blocks + tool schemas 27 tools + first-message scaffolding 7,997 chars of `<system-reminder>`), OpenCode 6,900 tokens (1 system block + 10 tools + no scaffolding)**——**Claude Code 對 OpenCode baseline overhead 4.7× 差距**; (b) **Cache efficiency: OpenCode request prefix byte-identical 在每 run, Claude Code mid-session re-write tens of thousands of prompt-cache tokens, on same task 寫到 54× more cache tokens than OpenCode**; (c) **Config bloat: 72KB AGENTS.md / CLAUDE.md instruction file 加 20,000 tokens to every request, 5 個 MCP servers 加 5,000-7,000 tokens, 真實 production setup 75,000-85,000 tokens before user types a word**; (d) **Subagent cost: 121,000 tokens task 直接執行 cost, 透過 2 個 subagent fan-out cost 513,000 tokens (4.2× 倍增, 每 subagent 有 own bootstrap cost, parent 然後 consume transcript)**——**「**first high-engagement independent wire-level 量化 coding agent unit cost**」 的具體 new reference**。

> **架構性解讀**: 這個 measurement 的 **結構性意義是「**coding agent 從 功能 feature 走到 unit cost transparency**」 的具體 new industry baseline**。 具體三層:
> 1. **「**Coding agent 4.7× baseline overhead 差距 對 企業 IT cost baseline 的具體 new structural insight**」**: systima.ai 量化 證明 Claude Code 對 OpenCode 在 「**22 character prompt**」 下 overhead 4.7×, 在 production setup (72KB AGENTS.md + 5 MCP servers) 下 75,000-85,000 tokens per request before user types——**「**frontier coding agent 的 unit economics 在 2026 H2 必須 wire-level 量化, 不能依賴 vendor dashboard**」 的具體 new evaluation standard**, 對企業 IT 是 「**coding agent 採購的 TCO model 必須 include baseline overhead + cache write cost + MCP server cost + subagent cost 四 dimension**」 的具體 new 2026 H2 baseline
