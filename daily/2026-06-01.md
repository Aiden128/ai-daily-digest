**OpenAI 模型首次自主證明離散幾何學 80 年難題，推翻 Erdős 猜想** —— OpenAI 於 5 月 29 日發表突破性成果：其內部通用推理模型（非專為數學設計）自主發現了一個無限構造族，證明了平面單位距離問題（planar unit distance problem）中「方格網建構本質上最優」這一長期猜想是錯誤的。這是首次有 AI 系統在無人類數學家主導的情況下，自主解決一個核心子領域的知名開放問題。證明已通過外部數學家群組檢驗，並由 Fields 獎得主 Tim Gowers 撰寫伴隨論文稱之為「AI 數學的里程碑」。

> 深度分析：這個問題由 Paul Erdős 於 1946 年提出，歷經近 80 年未被解決。傳統上，數學界認為方格網的變體構造已接近最優，只能達到 $n^{1+o(1)}$ 量級的單位距離對。OpenAI 模型發現的構造利用了代數數論中「無限類域塔（infinite class field towers）」與 Golod–Shafarevich 理論，證明了存在固定指數 $\delta>0$（後續 refinement 由 Princeton 教授 Will Sawin 確定為 $\delta=0.014$），使得無窮多個 $n$ 可達到 $n^{1+\delta}$ 對。這不僅是一個具體猜想的否定，更揭示了代數數論與離散幾何之間前所未有的深刻聯繫。Gowers 指出，這可能為數學家開闢一條探索兩個遙遠領域之間橋樑的新路徑。對 AI 研究而言，這標誌著通用推理模型已具備「長距離概念連結」與「維持複雜論證一致性」的能力——這正是邁向自動化科學研究的關鍵門檻。

## 技術深潛

### LoRA 的記憶定律：為什麼你的微調模型「記不住」新知識？

arXiv:2605.30260（How LoRA Remembers? A Parametric Memory Law for LLM Finetuning）是近期最值得關注的訓練方法論論文之一。作者來自浙江大學與阿里巴巴，他們系統性地量化了一個長期困擾業界的問題：**LoRA 微調究竟能讓模型「記住」多少新知識？**

現有的 LoRA 研究主要依賴定性評估——「微調後在下游任務表現更好」，但這無法回答一個根本問題：如果我要讓模型精確記住 10,000 條事實，需要多大的 rank？訓練多少步？為什麼有些知識「記得牢」，有些卻「一學就忘」？

論文的核心貢獻是提出了**參數化記憶定律（Parametric Memory Law）**：一個冪律（power law）關係，將 loss 下降 $\Delta L$ 與有效參數數量及序列長度連結起來。具體而言，作者發現：

$$\Delta L \propto (\text{effective params})^{-\alpha} \cdot (\text{sequence length})^{-\beta}$$

這個冪律在不同模型規模與資料集上均表現穩健。更重要的是，在 token 層級的細粒度分析中，作者發現了一個確定性的**相變（phase transition）**：當某個 token 的預測機率 $p > 0.5$ 時，在貪婪解碼下即可實現逐字（verbatim）回憶。這個 $p > 0.5$ 的閾值是一個充分條件，意味著模型對該知識的「記憶」已從統計關聯轉變為確定性提取。

基於這個洞察，作者提出了 **MemFT（Memory-aware Fine-Tuning）**：一種閾值引導的優化策略，動態將訓練預算重新分配給「低於閾值的 token」（即模型尚未確定記住的知識），而非均勻分配給所有 token。實驗顯示，MemFT 能顯著提升記憶保真度與效率。

**對業界的啟示**：
1. **知識庫微調的容量規劃**：過去企業在為內部知識庫微調模型時，rank 的選擇往往是試誤法。這個冪律提供了一個理論依據——若要記住 $N$ 條事實，可以根據冪律反推所需的 effective parameters。
2. **RAG vs. 微調的權衡**：如果目標知識的數量超過 LoRA 的冪律容量上限，則 RAG（檢索增強生成）是比微調更經濟的選擇。這個「分界線」過去只能靠經驗猜測，現在有了量化工具。
3. **持續學習（continual learning）**：對於需要不斷更新知識的應用（如法律條文、醫療指南），MemFT 的動態預算分配可能比標準 LoRA 更有效率，因為它能優先鞏固「快要記住但尚未記牢」的新知識。

### VoxCPM2：無 Tokenizer 的端到端多語言 TTS 系統

OpenBMB 開源的 VoxCPM2 持續升溫，目前已進入 GitHub Trending。這是一個無需離散 tokenizer 的 Text-to-Speech 系統，直接透過端到端擴散自迴歸架構生成連續語音表徵。VoxCPM2 為 2B 參數模型，支援 30 種語言、Voice Design（以自然語言描述創建新聲音）、可控語音克隆，並輸出 48kHz 高品質音訊。在 NVIDIA RTX 4090 上 RTF 可達 ~0.3，透過 vLLM-Omni 加速更可降至 ~0.13。其「無 tokenizer」設計消除了離散化過程中的資訊損失，在情感表達與語調細節上具有潛在優勢，且採用 Apache-2.0 授權可商用。

**核心價值**：語音生成領域正經歷從「離散 token」（如 SoundStream、EnCodec）向「連續表徵」（如 flow matching、diffusion）的範式轉移，VoxCPM2 是目前最完整且開源可商用的實作之一。

### Microsoft markitdown：AI 文件管線的標準前置工具

## 研究亮點

### LLMSurgeon：逆向工程大語言模型的「數位 DNA」

**Authors**: Yaxin Luo, Jiacheng Cui, Xiaohan Zhao, et al.  
**Link**: [arXiv:2605.30348](https://arxiv.org/abs/2605.30348) (ACL 2026 Main)

**核心貢獻**：大型語言模型的預訓練資料混合物（data mixture）構成了它們的「數位 DNA」，塑造了模型的行為、能力與失效模式。然而，這種組成極少被公開，使得事後審計幾乎不可能。LLMSurgeon 將「資料混合物手術（Data Mixture Surgery, DMS）」形式化為一個逆問題：在僅有目標 LLM 生成文本的情況下，估計其預訓練語料庫在預定義分類法下的領域級分布。

方法上，LLMSurgeon 不直接聚合分類器輸出（這會受到系統性領域混淆的影響），而是估計一個經過校準的「軟混淆矩陣（soft confusion matrix）」，並求解約束逆問題來修正系統性偏差，恢復潛在的混合先驗。為了評估，作者引入了 LLMScan——一個基於開源 LLM 的、配方可驗證的評估套件。實驗顯示 LLMSurgeon 能以高保真度恢復領域混合物。

**💡 實用價值**：對於需要審計第三方模型（如企業採購的閉源 LLM、法律訴訟中的模型證據）的場景，LLMSurgeon 提供了一種無需訓練資料存取即可推斷模型「背景」的實用工具。這對於 AI 治理、模型溯源（provenance）與合規審計具有直接意義。

### Demystifying Data Organization for Enhanced LLM Training

**Authors**: Yalun Dai, Yangyu Huang, Tongshen Yang, et al. (Microsoft)  
**Link**: [arXiv:2605.30334](https://arxiv.org/abs/2605.30334) (ACL 2026 Main)

**核心貢獻**：資料選擇（data selection）已被廣泛研究，但「資料組織（data organization）」——即訓練樣本的排序與分組策略——在 LLM 訓練中卻長期被忽視，尤其因為現代 LLM 通常只訓練一個或幾個 epoch。這篇論文系統性地探索了資料組織對 LLM 訓練的影響，並形式化了四個關鍵指導原則：

1. **Boundary Sharpening（邊界銳化）**：在資料邊界處增強訊號，幫助模型區分不同領域或難度的樣本。
2. **Cyclic Scheduling（循環調度）**：通過週期性重複特定模式，鞏固關鍵知識的學習。
3. **Curriculum Continuity（課程連續性）**：保持課程學習的平滑過渡，避免難度跳變造成的訓練不穩定。
4. **Local Diversity（局部多樣性）**：在每個局部訓練窗口內保持資料多樣性，防止模式崩潰。

基於這四個原則，作者提出了兩種新穎的資料排序方法 STR 與 SAW，並在不同模型規模與資料規模上驗證了其對預訓練與 SFT 階段的穩定性與性能提升。值得注意的是，這些方法幾乎不增加額外計算成本，因為它們重用了為資料選擇預先計算的樣本級分數。

**💡 實用價值**：對於正在進行自有 LLM 預訓練或領域適應的企業與研究團隊，這篇論文提供了一個低成本、高回報的優化維度。資料排序不需要改變模型架構或增加訓練步數，只需要在資料管線中插入一個排序模組——這是典型的「事半功倍」改進。
